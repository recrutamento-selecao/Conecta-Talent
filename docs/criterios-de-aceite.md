# Evidências da sprint do Thiago

## Verificações executadas

- As cinco rotas abriram com uma única entrada HTML.
- Cada rota exibiu uma única raiz `.pagina-recrutamento`.
- Cada página exibiu a sidebar compartilhada com cinco links.
- Os 15 módulos JavaScript passaram na verificação de sintaxe.
- Não foram encontrados `document.body`, `DOMContentLoaded` ou `document.querySelector` global nos módulos de página.
- O formulário de criar vaga exibiu oito erros visíveis quando enviado vazio.
- A tela de senha exibiu erros para senha atual, nova senha e confirmação vazias.
- Uma nova etapa foi adicionada e a lista passou de quatro para cinco itens.
- O envio válido de criar vaga produziu um objeto com o título informado.
- O navegador não registrou erros no console durante os testes.
